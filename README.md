# Mi Portafolio — Práctica 1

Portafolio web estático creado para la práctica de despliegue con GitHub y Dokploy.

## Estructura
- `index.html` — página principal
- `style.css` — estilos
- `script.js` — JavaScript
- `Dockerfile` — configuración para desplegar con Docker/Dokploy

## Antes de entregar
1. Cambiar `Tu Nombre` por el nombre del estudiante.
2. Cambiar `correo@ejemplo.com` por un correo de contacto.
3. Sustituir los proyectos de ejemplo por proyectos reales.
4. Agregar una foto o avatar si el profesor lo solicita.

## Despliegue
El proyecto puede desplegarse en Dokploy como una aplicación usando GitHub como fuente y `Dockerfile` como tipo de construcción.
